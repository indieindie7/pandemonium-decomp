Second review of provisional function names in a Sega Saturn SH-2 game decompile (Pandemonium!, Crystal Dynamics / Toys for Bob 1996, Saturn port by Jumpin' Jack Software, 1997). Research only.
These names were marked provisional by a first naming pass. Now each entry also has its callers.
Entry layout: "#### PROG 0x<addr> <name> | <comment>", then the function decompile, then "---- callers: N (names)", then up to 3 caller decompiles.
Literal-pool pointers are resolved: &name or &DAT_<addr> is the address the code uses; PTR_<name>_<addr> is a pointer to a named function.
Context: two programs. KERN at 0x06004000 (main game; SBL library region about 0x06039000-0x0604b000: CDC_*, GFS_*, SMPC, SCL, DMA) and DUCK at 0x060f0000 (FMV movie player, movie_/pcm_ names). 2.5D platformer on a 3D rail path: player movement/jump, path camera, enemies, collision, pickups, level loading from JESTERS.PKG, VDP1 polygons, VDP2 backgrounds, sound, pad input, menus/passwords. Name from what the code does; never copy text from any leaked source.
Saturn memory map: 0x25c00000 VDP1 VRAM, 0x25d00000 VDP1 regs, 0x25e00000 VDP2 VRAM, 0x25f00000 VDP2 color RAM, 0x25f80000 VDP2 regs, 0x25a00000 sound RAM, 0x25b00000 SCSP, 0x25fe0000 SCU, 0x20100000 SMPC, 0x25890000 CD block, 0xfffffe00.. SH-2 on-chip, 0x21000000/0x21800000 slave SH-2 signal.
Rule: read EVERY entry's body and its callers before deciding. Do not decide from the name or comment alone; do not skim. Read the file in pieces (offset/limit, about 600 lines at a time) until the end.
For each entry decide, using the body AND how callers use it (arguments passed, result used, the caller's own name and job):
- CONFIRM: the name fits.
- RENAME: a clearly better name (same style: lowercase module prefix + CamelCase, letters digits underscore, no _<number> suffix; official SBL names like CDC_/GFS_ only when the behaviour clearly matches).
- UNSURE: still not enough evidence. Keep it.
Write each verdict line to the result file as soon as you decide it (append as you go), in input order, exactly:
<PROG> 0x<addr> <oldname> CONFIRM|RENAME|UNSURE <newname or oldname> <short reason, one line>
Every entry gets exactly one line. Do not quote game text longer than 3 words. Edit no other file. At the end reply only with the counts.
